ЛАБОРАТОРНАЯ РАБОТА № 7

Тема: Создание простого одностраничного приложения (SPA) без фреймворков: навигация по вкладкам, динамическая подгрузка контента.

Дисциплина: Языки и технология программирования.

Вариант № 20: SPA «Управление мероприятиями».

1. Цель работы

Изучить принципы создания одностраничных веб-приложений с использованием HTML5, CSS3 и JavaScript без применения сторонних фреймворков. Освоить управление DOM, обработку событий, динамическое отображение данных, создание и проверку форм.

2. Задачи работы
Создать интерфейс приложения с вкладками «События», «Регистрация», «Участники».
Реализовать переключение вкладок без перезагрузки страницы.
Организовать хранение данных мероприятий и участников в JavaScript.
Создать форму регистрации на мероприятие.
Реализовать проверку корректности введённых данных.
Обеспечить динамическое отображение списка зарегистрированных участников.
Добавить счётчик регистраций и возможность удаления регистрации.
Обеспечить адаптивность интерфейса для мобильных устройств.
3. Описание приложения

Разработанное приложение предназначено для демонстрации системы управления мероприятиями.

Приложение содержит три основных раздела:

События — отображает список мероприятий, даты проведения, места и описания. Пользователь может перейти непосредственно к регистрации на выбранное мероприятие.
Регистрация — позволяет ввести имя, электронную почту, выбрать мероприятие и добавить комментарий. Перед сохранением выполняется проверка данных.
Участники — отображает список зарегистрированных участников, выбранные мероприятия и количество регистраций. Предусмотрена возможность удаления записи.

Переход между разделами осуществляется средствами JavaScript без полной перезагрузки страницы.

4. Используемые технологии
HTML5 — структура веб-страницы.
CSS3 — оформление интерфейса и адаптивная верстка.
JavaScript — обработка событий, управление DOM, проверка данных и обновление содержимого.

В работе не используются React, Vue, Angular, jQuery и другие сторонние SPA-фреймворки.

5. Структура проекта

Проект состоит из трёх файлов:

index.html — структура страницы, заголовок, навигация и контейнер содержимого.
style.css — оформление вкладок, карточек мероприятий, формы и списка участников.
app.js — данные мероприятий, регистрация пользователей, обработчики событий и динамическое формирование содержимого.
6. Основные алгоритмы работы

При запуске приложения отображается вкладка «События». Навигационные кнопки обрабатываются методом addEventListener(). При выборе вкладки вызывается функция showPage(), которая определяет необходимый раздел и обновляет содержимое страницы.

Данные мероприятий хранятся в массиве объектов events. Данные зарегистрированных участников хранятся в массиве participants.

При отправке формы приложение проверяет имя, адрес электронной почты и выбранное мероприятие. Также выполняется проверка повторной регистрации одного адреса электронной почты на одно и то же мероприятие.

Если данные корректны, запись добавляется в массив участников. Список участников и счётчики формируются динамически средствами DOM.

Для создания HTML-элементов применяется document.createElement(), а для вывода текстовых данных используется textContent. Это позволяет избежать интерпретации введённого пользователем текста как HTML-разметки.

7. Тестирование приложения
№	Проверка	Ожидаемый результат
1	Запуск приложения	Отображается список мероприятий
2	Переключение вкладок	Содержимое меняется без перезагрузки страницы
3	Регистрация с корректными данными	Участник добавляется в список
4	Отправка пустой формы	Браузер сообщает о необходимости заполнить обязательные поля
5	Ввод некорректного адреса электронной почты	Форма не отправляется
6	Повторная регистрация на то же мероприятие с тем же адресом	Появляется сообщение о повторной регистрации
7	Удаление участника	Запись удаляется, счётчик обновляется
8	Просмотр приложения на узком экране	Элементы интерфейса отображаются в удобном формате

После фактического запуска проекта необходимо указать результат каждой проверки: «Пройден» или «Не пройден».

8. Дополнительная функциональность

В качестве дополнительного задания реализованы счётчик регистраций, автоматическая проверка повторных записей и удаление регистрации. Эти возможности делают приложение интерактивным и позволяют изменять данные без перезагрузки страницы.

9. Вывод

В ходе лабораторной работы было создано одностраничное приложение «Управление мероприятиями» с использованием HTML5, CSS3 и JavaScript без фреймворков.

Были реализованы навигация по вкладкам, динамическое формирование содержимого, обработка пользовательских событий, проверка формы регистрации, добавление и удаление участников, а также обновление счётчиков.

В результате работы были закреплены навыки управления DOM, организации данных в JavaScript и создания интерактивных веб-интерфейсов.
